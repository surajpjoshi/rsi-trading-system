# RSI Trading System

Independent Phase 4 + Phase 5 + Phase 6 project.

Signal:
1. Weekly RSI > 50
2. Hourly RSI has touched <= 30
3. Latest completed 15m Close > Previous 15m High
4. SETUP when all conditions are satisfied

The existing `rsi-dashboard` project is not used by this repository.

The Upstox token is supplied through `UPSTOX_ACCESS_TOKEN`.
